# Экспорт своего словаря Preply в Anki

Программа читает **ваш** список Vocabulary на preply.com и собирает колоду `.apkg`. Пароль она не спрашивает и никуда не записывает. Чужие аккаунты и чужие списки она не обходит.

Образец полей — колода `Ultimate English Collection EN-def (with audio).apkg`. Исходный файл на рабочем столе программа не изменяет.

## Что попадает в карточку

Тип заметки: `EN definition (type-in + audio)`.

| Поле | Содержимое |
| --- | --- |
| Front | Определение на языке слова (для английского — английское). Его видно на лице карточки. |
| Back | Само слово (lexeme). Его нужно ввести в поле `{{type:Back}}`. |
| Audio | Произношение и примеры в том же виде, что в образце. |

Примеры и звук в поле Audio:

- есть звук и примеры: `[sound:vocab_0001_speak.mp3]<br><br>1. первый пример<br>2. второй пример`
- есть звук, нет примеров: `[sound:vocab_0003_English.wav]`
- звук не скачался, примеры есть: слово всё равно попадает в колоду, в поле остаются только пронумерованные примеры, а причина пишется в `.failures.json`

Имя файла: `vocab_0001_speak.ext`. Расширение такое, какое реально отдал Preply (wav, mp3, ogg или m4a). В колоде звук подключается тегом `[sound:...]`, как в образце. В настройках колоды включены `autoplay` и повтор звука, поэтому произношение играет на обороте.

Сначала идут примеры самой словарной записи, потом примеры определения. Повторы выкидываются, порядок сохраняется. Перевод на язык интерфейса в карточку не кладётся: определение monolingual, как в образце.

Теги у заметок пустые, как в образце. Колода по умолчанию называется `Preply Vocabulary`, чтобы новые карточки не смешались с вашей большой коллекцией. Тип заметки тот же, поэтому шаблон и CSS совпадают.

## Установка

Нужен Python 3.10 или новее.

```powershell
cd "D:\Projects\Preply extractor"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install chromium
```

Окно программы ставит браузер само; команда `playwright install chromium` нужна только для запуска из консоли.

## Окно программы

При запуске окно сначала проверяет компоненты: PySide6, requests, пакет Playwright и Chromium. У каждого компонента виден статус. Если чего-то нет, нажмите «Установить» — установка идёт в этом же окне, с полосой прогресса. Когда всё на месте, шаг входа открывается сам.

Браузер при запуске не открывается. Нажмите «Авторизоваться на Preply», чтобы войти в свой аккаунт. Дальше программа читает профиль и, если языков несколько, просит выбрать один. Если язык один, список открывается сразу. Пароль окно не спрашивает и не сохраняет.

Запускайте из папки проекта, чтобы использовался тот же профиль `.preply-profile`, что и у команды в консоли:

```powershell
python -m preply_extractor.gui
```

То же самое:

```powershell
python gui.py
```

Страница Preply открывается только после кнопки «Авторизоваться на Preply». Если браузера ещё нет, его ставит шаг проверки компонентов, а не консоль.

На шаге слов отметьте нужные. «Выделить все» и «Снять выделение» меняют отметки, «Обновить» заново читает словарь выбранного языка. «Далее» собирает колоду только из отмеченных слов. Когда файл готов, выберите папку и имя. Расширение `.apkg` добавится само. Если такой файл уже есть, программа спросит, заменять ли его.

Команда в консоли по-прежнему работает: `python -m preply_extractor`.

## Первый запуск: войти самому

Браузер откроется на вашей странице Vocabulary только после «Авторизоваться на Preply» (или после той же команды в консоли). Войдите в **свой** аккаунт в этом окне. Профиль сохранится в папке `.preply-profile` в каталоге проекта.

Окно — это установленный Google Chrome, если он есть на компьютере, иначе Chromium от Playwright. Каталог профиля отдельный. Это не профиль Chrome, которым вы пользуетесь каждый день: его куки и уже выполненный вход в Google сюда не попадают. Программа не копирует тот профиль и не закрывает Chrome, если он уже открыт. Первый вход через Google в окне программы запоминается в `.preply-profile`, и следующий запуск обычно входит сам. Пароль программа не спрашивает.

```powershell
python -m preply_extractor --subject english --ui-language en
```

То же самое:

```powershell
python export.py --output "output\Preply Vocabulary.apkg" --deck-name "Preply Vocabulary"
```

Когда сессия уже есть, можно без окна:

```powershell
python -m preply_extractor --headless --subject english
```

Готовый файл: `output\Preply Vocabulary.apkg`. Рядом будут `Preply Vocabulary.vocab.json` (ваш список, чтобы собрать колоду ещё раз без сайта) и `Preply Vocabulary.failures.json` (какие звуки не скачались). Если файл с таким именем уже есть, программа пишет новый, со штампом времени, и старый не затирает.

Импорт в Anki: File → Import. Карточки новые, прогресс повторений из Preply не переносится.

## Файл cookies вместо окна

Экспортируйте cookies **своего** браузера, где вы уже вошли на preply.com (Netscape `cookies.txt`, JSON из Cookie-Editor или одна строка заголовка `Cookie:`). Это не пароль.

```powershell
python -m preply_extractor --cookies "D:\path\to\cookies.txt" --subject english
```

Если сайт не примет файл и ответит отказом сессии, используйте окно браузера из раздела выше.

Свой HAR со страницы Vocabulary:

```powershell
python -m preply_extractor --har "D:\path\to\vocab.har" --cookies "D:\path\to\cookies.txt"
```

HAR содержит только те страницы, которые вы сами успели прокрутить. Полный список надёжнее забирать командой без `--har`: программа листает все страницы разделов Ready to practice, Up next и Learned.

Повторная сборка из сохранённого JSON:

```powershell
python -m preply_extractor --json "output\Preply Vocabulary.vocab.json" --cookies "D:\path\to\cookies.txt"
```

## Откуда берутся слова

Страница: `https://preply.com/en/practice/vocab-bank?subject=english`

Запрос тот же, что у этой страницы:

`POST https://preply.com/graphql/v2/VocabBankOverview`

Операция `VocabBankOverview`, поле `vocabularyBank`. Берутся три раздела вашего банка: `ADDED_READY_TO_PRACTICE`, `ADDED_UP_NEXT`, `ADDED_MASTERED`. Предложенные, но не сохранённые слова (`PENDING`) не экспортируются. У каждой записи: написание, выбранное определение, примеры и `pronunciationUrl`. Звук скачивается по этой ссылке с вашей сессией.

За один запуск — один предмет (`--subject`, по умолчанию `english`). Размер страницы как на сайте: 20, между страницами пауза 0,25 с. Другой предмет, например испанский, указывается отдельно: `--subject spanish`.
